# KTU Fashion & Graphic Design Website

## Real Content and Asset Requirements

This document lists the verified information, images, documents, links, and approvals needed to turn the current website into a complete production-ready department website.

The current website is a polished UI prototype. Some names, statistics, programmes, events, fees, claims, contact details, and images are placeholders and must not be published without verification.

---

## 1. What must be supplied first

Please provide the following before final content integration:

1. The official name of each department.
2. The official faculty or school under which each department belongs.
3. The correct public website URL for the department website, if different from `ktu.edu.gh`.
4. One approved contact person from the university.
5. One official source for admissions and fees.
6. Written confirmation that all supplied photographs and student work may be published.
7. The correct academic year and the date on which the information was last reviewed.

Every fact should include its source, such as an official KTU webpage, approved PDF, registry document, or confirmation from the department administrator.

## 13. Image and file delivery rules

Please deliver assets in a clearly named folder structure:

```text
content/
  university/
  fashion/
  graphic-design/
  faculty/
  facilities/
  portfolios/
  events/
  documents/
  legal/
  social/
```

Recommended file naming:

```text
department-subject-person-or-project-year-version.ext
```

Examples:

```text
fashion-studio-garment-construction-2026-01.jpg
graphic-project-brand-identity-student-name-2026-01.jpg
faculty-headshot-full-name-2026.jpg
event-runway-show-poster-2026.pdf
```

Do not send screenshots of text when an original document or editable text is available.
